# Aportes externos independientes

Este espacio conserva componentes opcionales propuestos por colaboradores sin
reemplazar el kernel NXK. Trabaja primero en un fork propio. Luego abre un pull
request que agregue solamente:

`APORTES-EXTERNOS/<alias>/<componente>/`

Cada aporte debe incluir su codigo, README con la relacion respecto a NXK,
instrucciones de construccion y pruebas ejecutadas. No pongas credenciales,
libros, herramientas ni archivos de compilacion. No copies aqui todo el kernel.

Aceptar una carpeta como aporte no instala ni conecta automaticamente ese codigo
al kernel. Para integrarlo se revisa aparte y el mantenedor debe aprobar el cambio.
