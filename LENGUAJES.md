# Lenguajes del proyecto

Fuentes versionadas; bytes normalizados a LF. No mide avance del kernel.
NEXTRY/NXJ se enumeran aqui porque GitHub Linguist no los reconoce como lenguajes propios.
NEXTRY ASM se presenta como Assembly en las estadisticas de GitHub.

| Lenguaje | Archivos | Bytes |
| --- | ---: | ---: |
| C (puentes y runtime) | 46 | 328419 |
| Ensamblador GNU | 6 | 5092 |
| NEXTRY | 17 | 9602 |
| NEXTRY ASM | 13 | 11486 |
| NXJ (prototipo) | 1 | 590 |
| PowerShell | 5 | 26733 |
| Python (compiladores y pruebas) | 35 | 205065 |
| Windows Batch | 12 | 4704 |

Regenerar: `tools/python/python.exe lenguaje/inventario_lenguajes.py`.
